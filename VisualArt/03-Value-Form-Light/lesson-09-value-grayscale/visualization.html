Value & thang xám — mô phỏng

Value là độ đậm nhạt (sáng-tối), độc lập với màu. Chơi với 3 công cụ dưới đây để tự mắt thấy: value dựng khối, và value mạnh hơn hue.

1. Thang value 9 bậc

Bấm một bậc để xem value của nó theo % và theo thang 0–255. Chia đều: bậc i có value = i/8 × 100%.
Bấm một ô ở trên…

2. Posterize — gom về N bậc (notan)

Khối cầu dưới đây được đổ bóng mượt. Kéo slider để gom cả nghìn mức xám về chỉ N mức. Ở 2–3 bậc, mắt vẫn đọc ra hình cầu — đó là bằng chứng chiều sâu nằm ở phân mảng sáng-tối.
9
N = 2 là notan cực đại: ngưỡng đúng ở 50% — pixel sáng hơn 50% thành trắng, tối hơn thành đen.

3. Bỏ màu → chỉ còn value

Hai mảng đều có hình tròn ở giữa. Bấm nút để chuyển sang grayscale (chỉ giữ value) và xem hình nào còn đọc được.
Trái: đỏ trên lục (khác hue, gần bằng value)
Phải: xanh lam tối trên vàng sáng (chọi value mạnh)
