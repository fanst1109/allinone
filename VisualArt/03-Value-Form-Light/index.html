Nhánh III — Giá trị, Hình khối & Ánh sáng

Biến hình phẳng thành khối có chiều sâu: độ đậm nhạt, ánh sáng đổ bóng, chất liệu và quy trình dựng tranh.

Nhánh này dạy gì?

  • Value & thang xám: vì sao độ đậm nhạt quan trọng hơn màu.
  • Đổ bóng khối cơ bản: 5 yếu tố ánh sáng trên cầu/lập phương/trụ.
  • Chất liệu: vẽ matte / glossy / metal / glass khác nhau thế nào.
  • Quy trình dựng tranh: line → value → color → detail (capstone).
